# 🔋 Battery Manager - 商用版

MacBookのバッテリー寿命を延ばすスマート充電管理アプリケーション

## ✨ 主な機能

- **🤖 自動充電制御**: 30%-78%の最適範囲で自動制御
- **📊 リアルタイム監視**: バッテリー状態のリアルタイム表示
- **🔌 スマートプラグ連携**: Tapo P110Mとの完全統合
- **⚙️ 簡単設定**: 直感的な設定画面とセットアップウィザード
- **🛡️ 安全機能**: 健全性監視・自動復旧システム

## 🚀 クイックスタート

### 1. インストール
```bash
# リポジトリをクローン
git clone https://github.com/Charlie5660/ultra-simple-battery-ui.git
cd ultra-simple-battery-ui

# インストール実行
chmod +x install.sh
./install.sh
```

### 2. 初回セットアップ
1. デスクトップの「Battery Manager.command」をダブルクリック
2. セットアップウィザードが自動起動
3. Tapo P110Mの認証情報を入力
4. 充電制御範囲を設定（推奨: 30%-78%）
5. 完了！自動的にアプリが起動します

### 3. 使用方法
- **自動制御ON**: バッテリーが30%以下で自動充電開始、78%以上で自動停止
- **手動制御**: 充電開始/停止ボタンで手動操作
- **設定変更**: ⚙️設定ボタンで充電範囲やデバイス設定を変更

## 📋 システム要件

- **OS**: macOS 10.14以降
- **Python**: 3.7以降
- **ハードウェア**: Tapo P110M スマートプラグ
- **ネットワーク**: Wi-Fi接続（Tapo通信用）

## 🔌 ハードウェア設定

### 必要な機器
1. **Tapo P110M**: TP-Link製スマートプラグ（電力監視機能付き）
2. **USB-C/MagSafe充電器**: MacBook用充電アダプタ

### 接続方法
1. Tapo P110Mをコンセントに接続
2. MacBookの充電器をTapo P110Mに接続
3. TapoアプリでP110Mの初期設定完了
4. Battery ManagerでTapo認証情報を設定

## ⚡ バッテリー最適化の科学

### なぜ30%-78%なのか？
- **リチウムイオンバッテリーの特性**: 満充電・完全放電はバッテリー劣化を促進
- **最適範囲**: 30%-78%での運用でバッテリー寿命が2-3倍延長
- **Apple推奨**: 最適化バッテリー充電機能と連携

### 効果
- **バッテリー寿命**: 最大3倍延長
- **充電サイクル**: 劣化速度を大幅軽減
- **発熱抑制**: 過充電による発熱を防止

## 🛡️ 安全機能

### 監視システム
- **120秒間隔**: バッテリー状態の定期監視

- **自動復旧**: 異常時の自動再起動

### 緊急機能

## 📊 技術仕様

### アーキテクチャ
```
Battery Manager App (tkinter GUI)
    ↓
Battery Controller Core (asyncio)
    ↓
Tapo P110M API (tapo library)
    ↓
Smart Plug Hardware Control
```

### 主要コンポーネント
- `battery_manager_app.py`: メインGUIアプリケーション
- `battery_controller_core.py`: バッテリー制御ロジック
- `setup_wizard.py`: 初回セットアップウィザード
- `app_config.py`: ユーザー設定ファイル

## 🔧 トラブルシューティング

### よくある問題

**Q: Tapoデバイスに接続できない**
- IPアドレスが正しいか確認
- Wi-Fi接続を確認
- Tapoアプリで事前設定が完了しているか確認

**Q: 充電制御が動作しない**
- 充電器がTapo P110Mに正しく接続されているか確認
- 自動制御がONになっているか確認
- ターミナルでエラーメッセージを確認

**Q: アプリが起動しない**
- Python 3がインストールされているか確認
- 必要ライブラリがインストールされているか確認: `pip3 list | grep tapo`
